# Comandos

Diga **"Jarvis"** e o comando, numa frase só ou com pausa ("Jarvis." / "Às suas ordens." / "abre o navegador"). Também dá para digitar na janela. Frases parecidas funcionam; a lista abaixo mostra exemplos, não frases obrigatórias.

## Controle do assistente

| Exemplo | Efeito |
|---|---|
| "Jarvis." / "Jarvis, preciso de você." | Responde na hora e aguarda o comando |
| "pare" / "chega" / chamar "Jarvis" enquanto ele fala | Interrompe a fala imediatamente |
| "cancele a última ação" / "desfaz" | Desfaz: volume, mudo, troca de voz, lembrete, programa aberto/fechado, edição de planilha |
| "interrompe a tarefa" | Para sequências e consultas longas |
| "dorme" / "Jarvis, acorda" | Modo espera: só reage a "acorda" |
| "desliga o microfone" | Desliga o microfone (religar: bandeja, botão ou `Ctrl+Alt+M`) |
| "muda para a Friday" / "volta pro Jarvis" | Troca o perfil de voz sem reiniciar |
| "fala mais devagar/rápido", "fala mais alto/baixo" | Ajusta a própria voz |
| "respostas curtas/detalhadas" | Tamanho das respostas |
| "desativa as respostas faladas" | Responde só na tela |
| "ativa/desativa o modo jogo", "modo silencioso" | Modos de foco |
| "o que você sabe fazer?" | Ajuda |

Atalhos globais (funcionam com jogo em tela cheia): `Ctrl+Alt+S` para a fala, `Ctrl+Alt+J` escuta sem palavra de ativação, `Ctrl+Alt+M` liga/desliga microfone. Controle Xbox: segurar **View + clique do analógico esquerdo** (falar) ou **View + clique do analógico direito** (parar). Tudo configurável.

## Música de fundo (modo Homem de Ferro)

Em **Configurações > Música**, escolha uma das opções:
- **Arquivo** seu (MP3, WAV, FLAC ou OGG, ex.: comprado na Amazon Music/iTunes): melhor experiência, a música abaixa sozinha quando o JARVIS escuta e fala.
- **Link** do Spotify ou YouTube (há botões prontos para "Back in Black" e "Shoot to Thrill"): o app abre a música; o volume fica por conta dele.

| Exemplo | Efeito |
|---|---|
| "Jarvis, modo Homem de Ferro" / "Jarvis, cheguei em casa" / "hora do show" | Toca a sua trilha com entrada suave |
| "toca a música" / "para a música" | Liga e desliga |
| "aumenta a música" / "abaixa a música" | Volume da música (separado do volume do Windows) |
| "Jarvis, pare" | Para a fala e a música |

A música abaixa sozinha enquanto o JARVIS escuta (para não atrapalhar o reconhecimento) e enquanto ele fala. Opções: tocar ao iniciar o JARVIS (nunca durante jogos), repetir e tocar só os primeiros segundos. Também pela bandeja: **Música de fundo**.

## Comandos personalizados (sem programar)

**Configurações > Comandos**, em JSON:

```json
[
  {
    "phrases": ["modo trabalho", "começar o expediente"],
    "actions": [
      {"action": "open_target", "target": "outlook"},
      {"action": "excel_open", "workbook": "pendências"},
      {"action": "wait", "seconds": 2},
      {"action": "email_unread"}
    ],
    "response": "Modo trabalho ativado.",
    "confirm": false
  },
  {
    "phrases": ["hora do jogo"],
    "actions": [
      {"action": "game_mode", "active": true},
      {"action": "notifications_mute", "minutes": 90},
      {"action": "open_target", "target": "storm 4"}
    ],
    "response": "Bom jogo. Notificações em silêncio por uma hora e meia."
  }
]
```

As ações aceitas são as mesmas da lista exibida na tela (`open_target`, `close_app`, `volume_set`, `open_url`, `reminder_create`, `excel_pending`, ...). Ações de risco mantêm a própria confirmação mesmo dentro de sequências. Comandos de terminal arbitrários não são aceitos.

Atalhos de programas, sites e jogos ficam em **Atalhos de programas/sites**:

```json
{
  "storm 4": {"type": "steam", "appid": "349040"},
  "sistema da empresa": {"type": "url", "url": "https://sistema.empresa.com.br"},
  "planilha local": {"type": "path", "path": "C:\\Users\\Voce\\Documents\\controle.xlsx"},
  "backup": {"type": "command", "argv": ["C:\\Ferramentas\\backup.exe", "--rapido"]}
}
```

O tipo `command` só executa o que **você** escreveu ali.

## Criar uma ação nova em Python

Crie um arquivo em `jarvis/actions/`, importe-o em `jarvis/actions/__init__.py`:

```python
from .base import STR, ActionResult, action, props

@action("abrir_chamado", "Abre o portal de chamados com o número informado.",
        props(["numero"], numero=STR))
def abrir_chamado(services, params):
    services.open_url(f"https://suporte.empresa.com/chamado/{params['numero']}")
    return ActionResult(f"Abrindo o chamado {params['numero']}.")
```

Com IA ativa, a nova ação já pode ser usada por frases livres. Para uma frase fixa sem IA, adicione uma regra em `jarvis/nlu/intents.py` ou crie um comando personalizado. Use `risk="confirm"` para ações que alteram dados.
